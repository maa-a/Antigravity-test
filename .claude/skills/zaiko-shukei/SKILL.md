# SAP在庫集計

添付ファイルのパスは引数またはユーザーのメッセージ（`@"/root/.claude/uploads/..."`）から取る。

## 手順

1. 元データの確認：シート `XTab DS_1` の列が
   `JANコード(EAN/UPC), 品目コード, 品目テキスト, 保管場所, 保管場所名, 在庫数量, 在庫金額` であること。
   違う場合は作業を止めてユーザーに確認する。
2. 出力名を決める：元ファイル名から日付部分（例 `26.10.5`）を取り、`output/<日付>_SAP_在庫集計.xlsx` とする。
3. 作成：
   ```bash
   python3 tools/sap_stock_summary/build.py <元データ.xlsx> output/<日付>_SAP_在庫集計.xlsx
   ```
4. 検証（`pip install formulas` が必要な場合あり。LibreOfficeは使わない）：
   ```bash
   python3 tools/sap_stock_summary/verify.py output/<日付>_SAP_在庫集計.xlsx
   ```
   `formula errors: []` と `row mismatches: 0` を確認する。
5. 出力は1ファイルだけにする：`output/` にある古い `*_在庫集計.xlsx` は `git rm` で削除する（git履歴には残る）。
6. コミットしてプッシュし、ファイルをユーザーに送る。

## 作成されるシート

- 元の `XTab DS_1`, `Filter DS_1` はそのまま残す。
- `倉庫別_<保管場所名>`：倉庫ごとに全品目。区分（重複/単独）列あり、重複は黄色。最後に「合計」「うち 重複」「うち 単独」。
- `商品別_合算`：全品目を1行ずつ。登録倉庫数、区分、倉庫ごとの数量・金額、合算在庫数量、合算在庫金額(原価)。最後に同じ3行の合計。
- 数量・金額はすべて元データを参照する SUMIFS 数式。

## 報告すること

- 品目数（重複・単独の内訳）、各シートの合計値。
- 経費行（品目コードが `Q` で始まる行）は数量列にも金額と同じ値が入っているため、数量合計を大きくしていることを注意として伝える。
