# 払出数量の在庫チェック


**作業の前に `memo/払出保留メモ.md` を確認し、対象の品目・会場・時期に当たる未対応項目があればユーザーに伝える。**

## 判定ルール（ユーザー確認済み）

- 照合は **E列の品目コード** で行う。F列の品目名は参考。
- SAP側で表示できない漢字が「?」になっている差は **同一商品** とみなす（例：案件管理表「虚式 茈 バスボール」＝ SAP「虚式 ? バスボール」）。
- 払出後の残数が **0 は問題なし**。**マイナスのみ NG**。
- 在庫は指示された倉庫だけを見る（指定がなければ CX催事 CX01）。他倉庫の在庫は足さない。
- 税区分（J列）は商品名と見比べて判断する。食品（お菓子など、品目カテゴリ「1009：食料品/飲料(8%)」）は「軽減 8%」、それ以外の商品は「課税10%」が正しい。
- **セット商品は同じ数だけ減らす**（ユーザー確認済み）：`CX2509JKSDTPCHCLP`（脱兎 ポーチ入りクリップセット）と `CX2509JKSDTPCHCLP2`（脱兎クリップのみ(1SET 5個)）は払出数・全倉庫合計の在庫数が常に同じになるはず。払出リストに片方しかない、数量が違う、在庫合計が違う場合は必ず指摘する。
- 「経費（課税8％）」などの経費行（品目コードが `Q` で始まる行）の「課税8％」は、8%の食品がある案件の経費であることを示す名前。経費行自体の税区分は「課税10%」で正しいので、誤りとして指摘しない。

## 手順

1. 案件管理表で対象シートを特定する。行・列の指示がある場合、ヘッダー（売項No./種別/品目カテゴリ/品目コード/売上項目/数量…）がその位置にあるシートを選ぶ。先頭シートとは限らない（例：`呪術廻戦2期展`）。
2. SAP在庫ファイルは、ユーザーが指定したもの（例：「26.10.5SAP」）を使う。
3. 実行：
   ```bash
   python3 tools/stock_check/check.py <案件管理表.xlsx> <シート名> <開始行> <終了行> <SAP在庫.xlsx> [保管場所コード] [--xlsx 出力.xlsx]
   ```
4. 一覧Excelが欲しいと言われたら `--xlsx output/<シート名>_払出チェック_<SAP日付>.xlsx` を付けて実行し、ファイルを送る。
5. 「減らした後の残数一覧（合算・倉庫別）」を求められたら、払出リストを「品目コード<TAB>数量」のTSVにして実行する（全品目×全倉庫、払出元の倉庫だけから差し引く）：
   ```bash
   python3 tools/stock_check/after_stock.py <SAP在庫.xlsx> <払出リスト.tsv> output/<名前>_払出後在庫一覧.xlsx [保管場所コード]
   ```
   指定倉庫で足りない品目を他の倉庫から払い出す場合は、TSVの3列目に払出元の保管場所コードを書く（例：`品目<TAB>68<TAB>CX01` と `品目<TAB>2<TAB>DB00` に分ける）。指定倉庫にある分はまず指定倉庫から、足りない分だけ他倉庫から減らす。
6. 報告：
   - **不足（マイナス）の商品**：品目コード、品目名、不足数量（払出数・在庫数も添える）。0件ならそう明言する。
   - 指定倉庫に品目コードがない商品があれば報告する。
   - 「?」以外の品目名の不一致があれば報告する。
   - 残数0の商品は問題ではないので、必要以上に強調しない（参考として件数程度）。
   - 指定倉庫で足りない商品は、どの倉庫（シート名 `倉庫別_<保管場所名>`）なら足りるか、不足数と在庫数を添えてリストで示す。
   - 新しいSAPデータが前回の払出を反映済みか（数量が払出数だけ減っているか）を確認し、反映済みなら二重に差し引かない。
